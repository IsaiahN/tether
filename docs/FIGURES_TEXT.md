121  Different routes can arrive at the same substance.
122  In chemistry this has been established since Liebig and Wöhler found two substances with the same composition and different properties, 1824 to
123  1826, and Berzelius named it isomerism in 1830. Two chains built from different links may compose functionally identical terms, and the converse
124  holds too: the same ingredients under a different bond are a different substance. Smoothness, symmetry, chaos and discreteness are each what a
125  particular composition leaves behind, and none is a seventh member. Figure 12 sets out the mapping and what it does and does not carry over.
126  WHY THE LINEAGE IS THE PROOF
127  The array cannot be checked by inspection, so the record is what makes it verifiable.
128  Nothing about a composed term tells you, from looking at it, which route produced it or whether that route was available. The space has no last
129  route and every turn begins from a remainder the last one left, so the order is not recoverable from the artefact. It is recoverable from the lineage.
130  A term carries the atoms it was built from and the bonds that joined them. That record is not documentation of the term. It is the term.
131  Which makes two different questions answerable, and the second is the one that is usually not.
132  The first is provenance: how did this come to be, and from what. The second is decidability: given the library as it stands, could this have been
133  reached at all. A system with a closure can answer that before it searches, and what it returns is a shape rather than a name.
134  So the system can report that it lacks something rather than producing an answer anyway. Unreachable is a verdict here, not a silence,
135  It cannot say which primitive is missing, because naming it would mean already holding it.
136  What it can do is narrow. It can say the question is not one question and must be split before it is searched again. It can characterise what is
137  missing in effect terms, which is the description that travels to a frame that may hold it. And it can say the answer is out of reach with the
138  library as it stands, so something has to be imported before it is asked again. Figure 9 puts it plainly: you get a kind of thing, never the
139  answer itself, and narrowing gets you close while the ground decides.
140  Which is what a hard decision needs and rarely gets: not only what was concluded, but what could have been concluded, and what would have had to
141  be true for the answer to differ. The composition is white box because the lineage is, and every claim in this figure is checkable the same way.
