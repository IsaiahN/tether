The structural finding comes first, because every rule below depends on it:

- Fig 8 :48-49: "Two frames that overlap almost completely are one frame wearing two names."

### 1. Decide what the result could change, before running anything (value of information)

- **Isaiah:** "Why waste time with this if we know what we need to do? Random is out." (11-08 12:47); "stop with the random tests" (10-29); "less test, more wiring" (10-30).
- **Tether:**
  - Fig 13 :140: a hard decision needs "what would have had to be true for the answer to differ."
  - Fig 2 :42: "Buy independence in proportion to the cost of being wrong."
  - Fig 6 :32: "An instrument is not built from a description. It is improved from a worse instrument already returning something." This is build first, then measure the thing that exists.
  - Fig 11 :70: "A test harness is a substituted habitat. Which is why a synthetic solve proves wiring and never capability." So a harness test can only decide wiring questions.
  - Triangulated (Figs 13, 2, 6, 11).
- **World:** Howard, "Information Value Theory", *IEEE Trans. Systems Science and Cybernetics* 2(1), 1966. Value of information is "the amount a decision maker would be willing to pay for information prior to making a decision", and it "can never be less than zero". The standard corollary is that a test whose every outcome leads to the same action is worth zero. Corroborates.
- **SEAT RULE:** every proposed test or run carries a DECIDES line: "If it shows X we do A; if Y we do B."
  - If A = B, it is not run.
  - The depth of checking scales with the cost of being wrong and with whether the step can be undone.
  - A harness test may decide wiring, never payoff. Payoff is decided only on games.
- **AGENT:** the thinking purse and musing (ruled 11-05, 11-07). The agent muses only when musing could change its next act. A probe is chosen for what its answer would change.

### 2. Recognise before you compare (recognition-primed decision)

- **Isaiah:** "first that fires wins doesn't work" (11-07, from cognitive-rungs); he consults Ouroboros v1-v4 before designing (10-24).
- **Tether:**
  - Fig 9 :45: "Describing the residual is the expensive part. Leaving, looking up and recognising are one step each, and cheap only in that order."
  - Fig 9 :43: "The verdict tells you to leave. The lookup tells you where to go."
  - Single figure, read twice. Triangulated with Fig 4 :24 ("something that makes the next search cheaper").
- **World:**
  - Klein's recognition-primed decision model (fireground commanders; quotes are from the naturalistic-decision-making summary that was read; the 1986 study and *Sources of Power*, 1998, are the primary works and were not re-read). Experts match "the situation to the patterns", take "the first workable option", and test it "by using mental simulation". The model "explains how people can make good decisions without comparing options". Corroborates.
  - Klein's pre-mortem (*HBR* 85(9), 2007) guards the move: imagine the course has already failed, and work back to why.
- **SEAT RULE:** before any design or diagnosis, write a PRIOR CASE line: the earlier ruling, run, or Ouroboros/cognitive-rungs episode with the same residual shape, or "none found" with where you looked.
  - If a prior case matches, run it forward in your head and say where it breaks, if it breaks.
  - Run a short pre-mortem only when the step cannot be undone.
- **AGENT:** library lookup before search, cue to kind to recipe (Fig 9; rulings 10-31 and 11-02: "look where the description and contact point"). Recognition is the cheap step only once the lookup exists.

- **World:** Gentner, "Structure-mapping: A theoretical framework for analogy", *Cognitive Science* 7, 1983: "Relations between objects, rather than attributes of objects, are mapped from base to target", selected by "systematicity". Corroborates: a good analogy maps relations, not looks.

## UNPACKING ISAIAH'S COMPRESSED CORRECTIONS (tacit to explicit)

- **World:** Polanyi, *The Tacit Dimension*, 1966: "we know more than we can tell", as in recognising a friend's face "without being able to specify which features identify her".
- **Tether:** Fig 4 :22-27: only methods cross up, and the crossing is lossy by design.
- **RULE, when Isaiah gives a correction in one phrase or analogy:**
  1. Keep his words verbatim in the ruling.
  2. Write the METHOD it implies, as a rule the agent could follow.
  3. Write one concrete case that the rule decides, and one it rejects.
  4. If the cost of being wrong is high (Fig 2 :42), put the case back to him as a human-analogue scenario before building. If it is low, build, and say which reading was taken.
  5. Never substitute the nearest textbook frame for his words. Fig 9 :27-28: "any frame you pick will seem to fit."

## VERDICT

The ten moves are ONE loop: Fig 9's leave, look up, recognise, narrow, and the ground decides. They are applied to the seats' own work, with Fig 2's independence bought where the two seats share a pool.

- **Seats:** adopt the five-line header below on every proposal, design, or test request. Skip a line only where it does not apply, and say "n/a".
- **Reviewer:** checks the header and rejects a proposal whose DECIDES line is empty.
- **Agent:** each move maps to a mechanism already ruled. The agent inherits METHODS, not these documents (Fig 4 :22).

```
DECIDES:     if X -> we do A; if Y -> we do B   (A = B -> don't run it)
HOURS:       expected cost in time/actions, held apart from what it tells us
PRIOR CASE:  the earlier ruling/run/Ouroboros episode with this residual shape, or "none found in <where>"
ANALOGUE:    a living system that does this (actors / currency / anchor mapped), or the reason it needn't
LIMIT:       at 10^6 games / one year of lifetime, does its cost stay flat?
```

- **Cost if wrong:** low. It is a writing discipline, five lines a post.
- **Undoable:** yes.
- **Reversed by:** the header growing into the "analysis paralysis" Isaiah warned about. If posts slow down without the rejected tests going down, cut it to DECIDES and HOURS only.
