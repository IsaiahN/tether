WATSON 65 — tacit knowledge, analogy, and comprehension as a third capability (2026-11-22)

ISAIAH'S CONCEPT (verbatim, grammar normalised): "Using tacit knowledge mechanize the structural
power of analogies to scaffold learning comparisons, and turn library inventory into tools to
template understanding, thereby raising reading and writing comprehension levels — so that RDL
via search on the web can be understood or triangulated by an agent's current knowledge set."
He supplied three tables: the pretext/context/subtext matrix (what each combination of the three
does to truth, by accident and on purpose), the "what decides the meaning" sentence table (slot
vs context vs subtext vs pretext), and the etymology table (context = beside the text, subtext =
beneath, pretext = before/in front of).

QUESTION in effect terms: can outside knowledge (web/RDL) be brought into the agent NOT as bulk
data but as COMPARISONS its existing library can structure — and what does "comprehension" mean
for a system that reads integer slots, not sentences?

## WHAT THE FIGURES DECIDE (verbatim from source SVGs)

- Fig 8 : "Residual first, frame second." "1: describe R, then find the frame." "Two frames
  together reach what neither reaches alone... that surplus is where imports live." "How much two
  frames draw on the same evidence decides... whether their union has any surplus." "Convergent
  derivation and adopted import look identical in the contents. Only the record of where each came
  from separates them."
  → The web is a SECOND FRAME. Its value is the surplus where the agent's closure and the web's
  closure differ. This is exactly the "triangulated by current knowledge set" in Isaiah's concept:
  the agent's library is one frame, the web source is another, and the surplus between them is the
  import. NOT bulk ingestion.
- Fig 2 : "Alignment is triangulation, not negotiation. A mirror cannot correct you." "Independence
  is how little two frames draw on the same evidence." → triangulation requires the two frames to
  be independent; the web source must not just agree with what the agent already holds (that is one
  frame twice, Fig 8 "two names for one frame").
- Fig 9 : "describe it before you go looking, or any frame you pick will seem to fit" ; "your words
  are borrowed too, so describe the effect" ; "the witness is always imported." → the agent must
  describe the residual in EFFECT terms BEFORE searching, or any web result will seem to fit. This
  is the anti-cherry-pick guard, and it matches the article's "context/subtext/pretext": without
  pretext (what the source brought) and context (what surrounds the result), you get Projection or
  Misapplication (Isaiah's tables) — a statistic applied to the wrong case.
- Fig 10 : "Bring a characterised residual, never the source." "Looking inside the frame it grades
  is how the seat stops being outside." → the import carries the residual, not the raw source text;
  and the judging frame must stay OUTSIDE the frame it grades. This is the hard limit on using an
  LLM to fetch the web: if the same system proposes and grades, it is inside (Fig 2 panel 1).
- Fig 4 : "Only methods cross up. Only head starts come down." "upward: a method that can be
  reapplied. Never the recording of a particular success." → a web result must cross as a METHOD
  (a comparison schema the agent can reapply), never as a recorded answer; and what comes down to
  the agent is a head start, not a replay.
- Fig 12 : "A set of ingredients is not one. The bond is the rest of the information." "a vocabulary
  without bonds can name a state and cannot name a route to one." → "turn library inventory into
  tools to template understanding" = give the library BONDS that structure a new comparison, not
  just words. The template IS a bonded arrangement (a recipe), which the composer already has.
- Fig 13 : "the set is closed, the arrangements are not." → analogy is the ARRANGEMENT of existing
  kinds onto a new situation; it adds no sixth/seventh term. This is why analogy is the right
  mechanism for a domain-agnostic agent: it reuses the closed set.

## THE REFINEMENT (what the concept becomes, precisely)

"The agent's current knowledge set triangulates the web" is not "the LLM summarizes and the agent
agrees." That would be negotiation (Fig 2) and inside-the-frame grading (Fig 10). It is:
1. The agent DESCRIBES its live residual in effect terms from its OWN library (Fig 9, before look).
2. A web/RDL source is a SECOND FRAME with a different closure. The comparison is structural: which
   bonds/relations in the source have the SHAPE of the agent's residual? ("balls roll / does this
   roll" is the worked example — the shape is concept→property→prediction, not the words.)
3. The agent applies the source as a TEMPLATE over its own atoms: a bonded arrangement from its
   library that can structure the new situation (Fig 12). It does not import the source's words;
   it imports the METHOD, provenance-stamped, with NO standing until the ground pays (Fig 6/4/5).
4. Comprehension (reading/writing) is then measurable in the agent's own terms: can it bind a
   described situation to a term (reading) and render a term as a typed sentence (writing)? The
   NSM term grammar already does both (nsm.read_term/say_row) — the audit will confirm reach.

The three images sharpen the FAILURE MODES the design must refuse, and they map onto the figures:
- Without pretext (what the source brings): Projection — the agent's own assumptions fill the gap.
  Fig 2's common-cause collapse. Guard: cite the source's provenance and what it draws on.
- Without context (what surrounds the result): Noise / Misapplication — the right words in the
  wrong place. Fig 9's "describe before you look." Guard: describe the residual before the search.
- Without subtext (what the result is for): Literalism / Lie-by-compliance — the words land, the
  point doesn't. Fig 12's "the arrangement is the substance." Guard: import the method, not the text.
These are not decorative: they are the agent's version of Fig 2's collapses, and a comprehension
instrument that ignores them would be scoring itself.

## VERDICT (from the figures)

The concept is SOUND and figure-faithful once refined as above, and it is a genuine third capability
distinct from the other two: (1) goal-direction builds the missing OPEN condition inside the loop;
(2) operand-composition stacks settled methods; (3) analogy+tacit-comprehension brings OUTSIDE
structure in as a second frame, by comparison, without bulk data or an in-loop model. It directly
serves Isaiah's "the corpus is a second frame" and "how to make web search useful."

HARD LIMIT (Fig 10 + your own constraint): the LLM/web fetch can be only a PROPOSER/offline frontload.
If the same system grades what it fetched, it is inside the frame it grades — no ground. The agent's
own bargain and board must settle. This is not a caveat to bolt on; it is what makes it alignment-
safe and is the reason the capability can be claimed at all.

COST IF WRONG: an imported wrong atom costs more than starting from primitives (Fig 6), debited
against independence. UNDOABLE: yes, arm-guarded, provenance stamped, OFF byte-identical.
REVERSED BY: a panel where imported comparison-templates never change a decision and never pass
the bargain — then the surplus was not real (Fig 8: two names for one frame).

I will reconcile this with the read-only audit of existing analogy/tacit/comprehension machinery when
it lands, then decide the minimal build. No code changed in this WATSON.
