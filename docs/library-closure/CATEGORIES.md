# The taxonomy, updated against the pruned list

**61 domains, six super-categories, 2,694 entries.** The domain count is unchanged — **nothing
was removed wholesale** — and every count below is recomputed from `ATOMS.md` rather than from
the original tables.

## What changed

**All 61 tier-7 monads are gone**, so the *Monad* row every domain used to end on is absent.
That is 61 entries and it is the single largest structural change.

**Two domains shrank sharply.** Thaumaturgical 51 → 26 and Noetic 45 → 41 after a second ruling
restored most of what a first pass had cut. **Everything else is within a few entries of where
it started.**

**And ten entries were restored by ruling** — `Movement`, `Chaos`, `Amalgamate`, `Separate`,
`Erase`, `Construct`, `Phantom`, `Conflate`, `Negotiate`, `Dissimulate` — **plus three added by
the miscibility ruling**: `Merge`, `Abut`, `Layer`.

## And one thing the original taxonomy got wrong

**The Ennead of Connection lists nine domains and names nine elements.** Node, Edge, Network,
Cluster, Hub, Bridge, Flow, Emergence, Whole — **eight of those are entries inside the Network
domain, not domains.**

**Corrected below.** It is a good sequence and it belongs one level down.

# The architectures

**Four of the original five hold. One is a category error and is corrected.**

## The becoming cycle

**Learning → Skill → Action → Transformation → renewed Learning.**

| phase | domain | function |
|---|---|---|
| acquisition | Learning | gathering knowledge and ability |
| refinement | Skill | perfecting applied ability |
| enactment | Action | executing it |
| change | Transformation | what results, and does not revert |

**Holds, and it is the ablation test's own shape.** Wipe what was acquired and see whether the
cycle regenerates it — **which is exactly *did it compose or was it handed*.**

## The agency cycle

**Desire → Curiosity → Thought → Choice → Action → Character → back to Desire.**

| domain | role |
|---|---|
| Desire | the engine |
| Curiosity | the driver of inquiry |
| Thought | the generator of possibilities |
| Choice | the selector among them |
| Action | the enactment |
| Character | the quality of the one choosing and acting |

**Holds, and it maps onto the loop directly** — Curiosity is the probe, Thought is the closure,
Choice is the mint's selection, Action is the bet, **and Character is what the ledger records
about how the selecting was done.**

## The continuity structure

**Lineage → Memory → Habit → Adherence → Character → Rebellion → Transformation.**

| domain | role |
|---|---|
| Lineage | the thread of descent |
| Mnemonic | the storage of the past |
| Habit | the groove of repetition |
| Adherence | the will to remain bound |
| Character | the integration |
| Rebellion | the courage to break |
| Transformation | what results |

**Holds, and it is the staleness question written as a cycle.** A library is commentary on past
rooms — **`Habit` is what it becomes when nothing checks it, `Adherence` is keeping it anyway,
and `Rebellion` is the room change forcing the issue.**

## The mastery path

**Learning → Practice → Skill → Flow → Mastery.**

**Holds with one correction: `Practice` is not a domain, it is `Habit`**, and `Flow` and
`Mastery` are entries rather than domains — Flow appears in Dynamic, Psychological and Noetic.
**So this is a sequence of four domains and two entries**, which is fine as a path and wrong as
a taxonomy row.

## The connection sequence — corrected

**The original lists nine domains and names nine elements.**

**Node · Edge · Network · Cluster · Hub · Bridge · Flow · Emergence · Whole** — **eight of these
are entries inside the Network domain.** Only *Network* is a domain.

**It is a good sequence and it belongs one level down**, as a reading of how a network is built
up from its parts. **Recorded as an element sequence within Network, not as a super-structure.**

# What the taxonomy still owes

**Entry-level categories — now specified, not applied.** See `ENTRY_CATEGORIES.md`: eight
kinds and nine axes, orthogonal to domain. **Nothing is tagged yet**, and one of the nine axes
is derivable from what is already recorded while the heaviest one is not.

**A cross-domain shape index.** Six shapes recur across three or more domains: **self-amplifying
output, the productive middle, pattern-in-noise, least-means-greatest-effect, bounded regions,
and the cause-effect delay.** They are marked at each site and are not indexed anywhere.

**And provenance per entry.** Human tier 1 cites developmental literature. **The other sixty
domains' tier-1 atoms cite nothing** — folk-level and bodily, but unattributed, which is the
distinction the `derived` / `chosen` / `unattributed` field already draws for mechanisms and
does not yet draw for these.
