# library

The agent's inherited knowledge: the ~2,700 atoms and recipes drawn from the human-prior set (`given.json`), the frame and index files, and the NSM grammar with its 68 prepositions (`grammar.json`, kept apart from the rest by ruling). `library_runtime.py` loads it and answers lookups; `build_library.py` rebuilds it from the sources (`--check` proves every derived file reproduces). `LIBRARY_DESIGN.md` and `LIBRARY_SPEC.md` describe the format. `ATTRIBUTE_INDEX.json` is Isaiah's attribute index (17 semantic clusters), moved here from docs/corpus/ in 8e (r1855): read by `inherited.py` and `build_library.py`, stored byte-for-byte (`-text` in .gitattributes) and sha256-checked at load -- never edit it. What the agent LEARNS is not here: that is its lifetime store (central), outside the repo.
