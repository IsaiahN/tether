# library

The agent's inherited knowledge: the ~2,700 atoms and recipes drawn from the human-prior set (`given.json`), the frame and index files, and the NSM grammar with its 68 prepositions (`grammar.json`, kept apart from the rest by ruling). `library_runtime.py` loads it and answers lookups; `build_library.py` rebuilds it from the sources (`--check` proves every derived file reproduces). `LIBRARY_DESIGN.md` and `LIBRARY_SPEC.md` describe the format. `ATTRIBUTE_INDEX.json` is Isaiah's attribute index (17 semantic clusters), moved here from docs/corpus/ in 8e (r1855): read by `inherited.py` and `build_library.py`, stored byte-for-byte (`-text` in .gitattributes) and sha256-checked at load -- never edit it. `tether_rules.json` is the Tether domain, method entries, run by the agenda (not built): the pilot (r1912 A), the Tether's rules as method cards, a corpus import Isaiah approved (2026-11-13 10:44), stored byte-for-byte (`-text`) with its sha256 held by `build_library.py --check`, kept apart from `given.json` and `index.json`; no code opens it yet. What the agent LEARNS is not here: that is its lifetime store (central), outside the repo.
