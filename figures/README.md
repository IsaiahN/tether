# figures

Isaiah's original Tether figures (1-13) plus the Operators and Symbols tables, as SVG. They outrank everything else in the repo: the code, the rulings and the docs answer to them. A text extraction with line numbers lives in `docs/01-FOUNDATIONS/03-FIGURES_TEXT.md` (regenerated by `conform/figtext.py`); cite a figure as `Fig N :line`. 8e checks these files against the canonical set on Isaiah's machine.
